## Pour récupérer votre Public Key :

1. Connectez-vous à votre compte EmailJS : https://dashboard.emailjs.com/
2. Allez dans **Account** > **General**
3. Copiez votre **Public Key** (il commence généralement par des lettres/ chiffres)
4. Mettez à jour le fichier `src/config/emailjs.config.ts` avec cette valeur

## Exemple de Public Key :
- Format : `xxxxxxxxxxxxx` ou `user_xxxxxxxxxxxxx`
- Longueur : généralement 17-20 caractères

Une fois la Public Key ajoutée, le formulaire sera complètement fonctionnel !
